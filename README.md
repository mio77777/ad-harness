# Ad Creative Harness — 自分の案を自分で採点し、弱い案だけ作り直す

**テーマ: モデルではなく、ハーネスをつくる**

広告クリエイティブエージェント（商品概要 → 見出し・コピー・画像プロンプト5案）に、
**検査 → 採点 → ピンポイント再生成** のループをハーネスとして追加し、効果を eval で測りました。

## 仕組み
```
generate(5案)
  └─ loop (最大2ラウンド)
       ├─ rules.py   決定的チェック: 文字数 / 誇大表現 / 特徴に触れているか / 英語の画像プロンプト / 見出しの重複
       ├─ judge      別モデルがルーブリックで採点（具体性・訴求力・ターゲット適合、temperature=0）
       └─ 違反あり or 7点未満の案だけ、指摘をフィードバックとして渡して作り直す（合格した案は触らない）
```
ポイント
- **ルールの検査（客観）とLLMの審査（主観）の二層**: LLMの自己採点の甘さを、決定的なルールで補う
- **生成役と審査役を別のモデルにできる**: 自分で自分を甘く採点するのを防ぐ
- **案単位で作り直す**: 全体を作り直さないので、良い案が壊れずトークンも節約できる
- **eval で公平に比べる**: baseline と harness の最終案を、同じ審査員が付け直して比較

## 実行
```bash
export LLM_BASE_URL="https://<ai& InferenceのBase URL>/v1"
export LLM_API_KEY="..."
export GEN_MODEL="<生成モデル 例: Qwen系>"
export JUDGE_MODEL="<審査モデル 例: DeepSeek系 / Kimi系>"

python3 harness.py 0        # 1商品のトレース表示（デモ用）
python3 eval.py --limit 3   # まず3件で確認
python3 eval.py             # 10件 → results.md / results.json
```
APIなしで動作確認するとき: `MOCK=1 python3 eval.py`（疑似応答なので、数字は発表に使わないこと）
